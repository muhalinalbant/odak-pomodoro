# Odak · Pomodoro (Android)

## APK'yı GitHub ile almak (bilgisayara bir şey kurmadan)
1. github.com'da yeni bir depo aç (ör. `odak-pomodoro`).
2. **Add file → Upload files** ile bu klasörün TÜM içeriğini yükle
   (gizli `.github` klasörü dahil; telefondan yüklüyorsan zip'i bilgisayarda açman daha kolay).
3. **Actions** sekmesinde "APK oluştur" çalışır (~3-5 dk).
4. Bitince çalıştırmaya tıkla → en altta **Odak-Pomodoro-APK** → indir, zip'i aç, `Odak-Pomodoro.apk`'yı telefona kur
   ("Bilinmeyen kaynaklardan yüklemeye izin ver" demen gerekebilir).

## Android Studio ile
Klasörü Android Studio'da aç → Build → Build APK(s).
